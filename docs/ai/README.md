# AI-assisted Development

Large language models (LLMs) have been used during the design and development of VidRe, primarily as technical discussion partners.

Their contributions include exploring architectural alternatives, reviewing implementation approaches, identifying potential problems, and assisting with documentation and code development.

The directories below preserve selected conversations and design discussions to make the influence of these tools on the development process transparent.

- `chatgpt/` — Discussions with OpenAI's ChatGPT.
- `deepseek/` — Discussions with DeepSeek.

These records are intended to document **design provenance**, not to establish AI authorship. Architectural decisions, implementation choices, and responsibility for the resulting software remain with the human developers.

LLM-generated suggestions are not necessarily correct, and archived discussions may contain proposals that were subsequently rejected or superseded.
