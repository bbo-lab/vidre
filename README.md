# VidRe

> vidre: Catalan for "glass" (from Latin 'vitrum')

Video recording software for scientific purposes.

## Introduction

VidRe delivers a modular videography suite designed for scientific applications. 
It enables recording from any video source with synchronized timing, audio, and 
other critical data streams. Built on a modular foundation, it supports 
essential capture workflows—including calibration—while seamlessly integrating 
real-time capabilities such as object recognition and feedback loops, 
fundamentally transforming experiment interaction.

Designed for both developers and end users, VidRe offers a C++ API for deep 
integration alongside a plugin-driven architecture that makes extending 
functionality straightforward. For complex configurations, an embedded Lua 
engine provides a lightweight yet powerful scripting layer. With its frontend 
and backend cleanly separated, the same core can power a full GUI desktop 
application or run silently as a headless service—ideal for server-based or 
embedded research setups.
